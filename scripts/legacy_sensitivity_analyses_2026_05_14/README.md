# Historical sensitivity generators

These scripts are byte-identical copies of `paper/legacy_reference/figure_rev1/sensitivity_analyses/*.py`. They preserve the source paths, historical figure numbering, dependencies and output names. The records deposit supplies the cited saved tables; these copies were not executed to replace historical outputs.

| Script | Outputs described by the source |
|---|---|
| `classify_novelty_three_class.py` | Three-class novelty classification of unmatched candidates. |
| `drug_target_class_enrichment_2026-05-14.py` | Drug target-class enrichment CSV, figure and suggested Results text (S12). |
| `effect_size_distribution_2026-05-14.py` | Effect-size distribution CSV, figure, caption and suggested Results text. |
| `external_db_crossvalidation_2026-05-14.py` | External-database annotation table, summary and figure (257 recovered records). |
| `extreme_tail_dedicated_analysis.py` | Extreme-tail volcano plot, category breakdown and pathway tables (historical ED15). |
| `power_analysis_in_vivo.py` | Retrospective minimum-detectable-effect table and power figure. |
| `prior_atlas_comparison_2026-05-14.py` | Prior-atlas comparison table, figure, caption and suggested Discussion. |
| `regen_multiclock_dnam_ed13.py` | DNAm cross-clock Spearman and Jaccard tables and heatmaps (historical ED13). |
| `sensitivity_pooled_3modality.py` | Pooled scoring-weight sensitivity table, figures and summary. |
| `tissue_direction_enrichment_2026-05-14.py` | Tissue-direction enrichment tables and figure (S11). |
