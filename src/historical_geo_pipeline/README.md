# Historical GEO pipeline source and provenance

`current/` preserves all 19 scripts copied from `/Entropy/kying/GEO_data/src` on 2026-10-04, byte for byte, including September 2026 input guards. Its original `README.md` and `MANIFEST.tsv` are preserved beside the copies. The root manifest includes those same rows with `current/` paths, the required provenance columns, and the original source paths and modification times. `current/` means the October 4 snapshot, not a live source checkout.

`as_run/` contains Git blobs selected for the historical output periods. Selection is a reconstruction from modification times and code, not a recorded execution receipt. When the last committed version cannot write the observed layout or QC table, the earliest later compatible version is also included and marked as a candidate. Files with multiple selected versions have the nine-character commit in their filename. The RNA producer is under `as_run/src_rna/`, because `src/tAge.py` does not write the RNA `clock_result` exports used by the verifier. `as_run/fun/clean_metadata.R` preserves the helper sourced by the metadata processor. All copies are unmodified `git show <commit>:<source_path>` bytes; the manifest records the full commit, committer date, SHA256, byte count, associated outputs and UTC output mtime range.

The bundle selection is every `GEO_data/` row of the rebuild bundle's `clockbase_data/BUNDLE_MANIFEST.tsv` (reference run final-2026-10-05; SHA256 65a781d8f340e25e8e30db97d5f8babb0f0e34d35e325d63a9c56c47ca0f2f7b). It names 22,691 GEO files. These include the `clock_result` exports of 135 human and 138 mouse RNA studies with their harmonized metadata, three extracted DNAm `processed_data` matrices (GSE62727, GSE69948, GSE81846), `result/hs_dnam_age.csv.gz` and `result/qced_human_dnam_age.csv`. The other per-study exports and matrices read by local verifier modules are not bundled. The table therefore distinguishes the bundle selection from local verifier inputs and upstream artifacts. For each endpoint, the selected Git version is the last script commit with a committer timestamp at or before that mtime. Every intervening script version was considered, with rename history followed for the causal and GrimAge scripts. Copy ancestry stops where a separate script was created. No family crosses a committed change between its oldest and newest mtimes; where the same script serves different periods, both periods are recorded separately. Modification times record the current files' last filesystem writes, not necessarily their computation dates. Many outputs cluster on 2025-05-05, alongside source files; copying or migration could have reset these times. A clean working tree today does not establish historical working-tree contents. Uncommitted edits, model coefficients, dependencies, command-line overrides and transport/merge steps cannot be recovered from these timestamps alone. The selected copies do not establish an exact rerun environment or prove which bytes executed.

The attribution limits are specific to these producers:

* `4_compute_age.py` writes `GEO_hs_dnam/biolearn_output/{GSE}.csv`, whereas the local verifier reads `GEO_hs_dnam/clock_result/{GSE}.csv`. The observed clock columns are compatible with its biolearn export, but `biolearn_output/` is absent today and no tracked GEO script writes the DNAm `clock_result` path. A rename/copy or another producer is unrecorded. Its April 2024 blob is a candidate for the prediction computation, not proof of the export's transport.
* `src_rna/2_run_rna_clock.py` at `b0f8f67b3` (2024-04-16) writes separate preprocessing-specific files. The observed human and mouse exports are `{GSE}.csv` with merged clock columns. That layout is first recorded at `62491dd08` (2026-06-14T04:37:32 UTC), after all observed May 2025 prediction mtimes. Both blobs are included. The later blob is compatible with production of these merged files, but whether identical changes were uncommitted in May 2025, or a later transport/merge preserved older mtimes, is unknown. It cannot be assigned a May 2025 execution date merely from compatibility.
* RNA preprocessing has the same gap: `b0f8f67b3` writes flat files, while `62491dd08` writes and moves them into the observed per-study directories. Both versions are included. `file.rename()` can preserve an earlier file mtime, so the final directory layout does not prove when preprocessing ran.
* The bundled RNA QC table was written 27 seconds before `2a7c6339a` (2026-06-14T04:56:23 UTC), which first adds `summarize_imputation_artifacts()` and this output path. Its source log reports 04:55:57 UTC and the matching output/input paths. The last committed blob at the table mtime, `62491dd08`, has no QC summarizer and cannot have written it. The table was therefore produced with an uncommitted implementation or another writer. `2a7c6339a` is the first recoverable compatible implementation; exact pre-commit execution bytes are unknowable. September guards do not describe this June execution.
* The local DNAm QC table was written before `7592b3b50` (2026-06-14T04:43:13 UTC), which first adds its summarizer. The last committed version is the April 2024 missingness-only script. The June blob is preserved as the recoverable compatible candidate, with the same pre-commit uncertainty. The May 2025 per-study missingness tables select the April blob, not this later QC revision.
* `old_4a_compute_causal_age.R` and `old_4b_compute_grimage.R` were named `4a_compute_causal_age.R` and `4b_compute_grimage.R` in November 2023. Their June 2026 rename preserves the bytes exactly. The selected copies retain the source paths/names of the historical commit, rather than pretending they were first created in 2026.
* `1_process_meta_data.R` writes `processed_metadata_preharmonize` and harmonized `processed_metadata`, not the three consolidated `result/*_meta.csv` files. No writer of those result files was found in the tracked GEO scripts or this repository's Python/R sources. Their consolidation and model-generated metadata provenance remain unresolved; they are not assigned to the metadata processor. Its sourced `fun/clean_metadata.R` selects `2b9fb43c3` (2023-12-01). The later helper change affects `get_desc()`; the extraction/harmonization functions are unchanged.
* The series-matrix downloader is `0_get_meta_data.R`; downloaded series matrices are external GEO responses, not matrices generated by the code. The extracted `.csv.gz` matrices are written by `1.2_extract_human_matrix.R`. The September 2026 empty-input guard is absent from its April 2024 selected blob. The September guards in the other prediction entry points are also later than all observed prediction mtimes; there is no evidence here of prediction recomputation after those changes.

Before saving, the 19 snapshot files and all selected Git blobs were scanned for API-key, secret, token and password terms, recognizable key formats and private-key markers. No credential values were found, so no values were replaced with `REDACTED`. The only term matches are local numeric `token` parser-test variables in the current DNAm guard test. No historical copy contains credential terms. Source bytes remain unchanged.
